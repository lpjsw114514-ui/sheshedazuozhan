🏁 竞赛模式（仅房主可设）

🚀 方式一 · 本地服务器联机（推荐，成员点链接即进）

⚠ 当前是 HTTPS 页面，浏览器禁止连接局域网服务器。请从房主电脑运行 1.exe 后，用控制台打印的 http://IP:端口 网址打开本游戏。

📥 下载联机服务端 1.exe（仅房主需要，约 85MB）
第 2 步 · 把成员链接发到群里（点开即入房）：

房主需保持 1.exe 窗口和本页面打开；关闭任一 = 房间解散。

方式二 · 手动邀请码（无需任何程序，跨网络也能用）
把成员的回传码粘贴进来

查看方法：Win+R → 输入 cmd → 输入 ipconfig → 看「IPv4 地址」。
填写后邀请码会带上真实 IP，可解决浏览器隐藏本机 IP 导致的连不上。

每来一位新成员，需再点一次「生成邀请码房间」。
房主刷新页面 = 房间解散；房主页面请保持前台打开。

🚀 方式一 · 输入服务器地址 + 房间号加入

⚠ 当前是 HTTPS 页面，浏览器禁止连接局域网服务器。请直接点开房主发的成员链接（http://IP:端口/?room=NNNNNN）。

最省事的方式：直接点开房主发的成员链接，会自动带上房间号。

方式二 · 手动邀请码（无需任何程序）
把应答码发回给房主

查看方法：Win+R → 输入 cmd → 输入 ipconfig → 看「IPv4 地址」。

发给房主后等他点「确认该成员连接」，收到游戏画面即自动进房。
